# Money's Physics Lab | 錢錢的物理互動模擬實驗室

歡迎來到 **Money's Physics Lab**！這是一個專為中學物理教學與自主學習設計的 **Web 互動模擬實驗室**。
透過直覺的視覺化操作介面與即時圖表，將抽象的物理概念轉化為可互動、可探索的動態實驗

🌐 **線上體驗網址**：[https://money-lin.github.io/Money-Physics-Lab/]
---

## 👩🏻‍🏫 About Me

我是一名來自臺灣的國中理化老師。我在上課時，經常會需要使用動畫模擬來輔助說明。
雖然網路上已經有各種大大小小的教材與網站，但有些設計不太適合臺灣國中生的學習情境與課程重點。
因此，我決定在這裡建置一些在網路上較難找到、或是現有工具沒那麼好用的模擬實驗。
希望這些工具能幫助學生更好地理解理化概念！
如果有任何使用建議或教學上的回饋，非常歡迎與我聯繫交流。

---

## 💻 使用技術 (Tech Stack)

* **前端語言**：HTML5, CSS3, JavaScript (ES6+)
* **3D 渲染引擎**：[Three.js](https://threejs.org/)
* **繪圖與圖表**：HTML5 Canvas API
* **佈署平台**：GitHub Pages

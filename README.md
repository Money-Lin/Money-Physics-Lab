# ⚛️ Money's Physics Lab | 物理互動模擬實驗室

歡迎來到 **Money's Physics Lab**！這是一個專為中學物理教學與自主學習設計的 **Web 3D/2D 互動模擬實驗室**[cite: 1, 2]。
透過直覺的視覺化操作介面與即時圖表，將抽象的物理概念轉化為可互動、可探索的動態實驗[cite: 1, 2]。

🌐 **線上體驗網址**：[https://money-lin.github.io/Money-Physics-Lab/]

---

## 🛠️ 模擬單元介紹

### 1. 📷 3D 針孔成像實驗室 (`pinhole.html`)[cite: 2]
基於 **Three.js** 打造的 3D 光學物理模擬[cite: 2]。直覺呈現幾何光學中光線直線傳播與針孔成像的原理[cite: 2]。

* **核心特色**：
  * **多元光源模式**：提供「三色 LED (紅藍綠)」與「字母 F」兩種光源[cite: 2]。
  * **靈活參數控制**：可自由切換 1~3 個針孔數量[cite: 2]，並支援即時滑鼠拖曳（改變物距與像距）[cite: 2]。
  * **互動與即時模式**：支援「即時成像」與「點擊發光（粒子光路動畫）」互動探索[cite: 2]。
  * **精確物像關係**：自動即時計算與顯示物距 $d_o$、像距 $d_i$ 與放大率 $M$[cite: 2]。

---

### 2. 🚀 運動學演示 · 位置、速度與加速度 (`kinematics.html`)[cite: 1]
針對一維直線運動概念（Position, Velocity, Acceleration）設計的動態演示工具[cite: 1]。

* **核心特色**：
  * **即時連動圖表**：動態繪製 $x-t$（位置-時間）、$v-t$（速度-時間）與 $a-t$（加速度-時間）關係圖[cite: 1]。
  * **豐富運動情境**：內建「悠閒散步」、「走走停停」、「折返跑」、「衝刺煞停」等多種日常運動行為模式[cite: 1]。
  * **自我挑戰隨堂測驗**：內建「出題模式」，隱藏運動名稱與主控數值，讓學生透過圖形反推運動型態[cite: 1]。
  * **數據記錄與取樣**：提供不同時間間隔（1s / 0.5s / 0.2s / 連續）的數據表格，便於分析與教學匯出[cite: 1]。

## 💻 使用技術 (Tech Stack)

* **前端語言**：HTML5, CSS3, JavaScript (ES6+)[cite: 1, 2]
* **3D 渲染引擎**：[Three.js](https://threejs.org/) (用於針孔成像)[cite: 2]
* **繪圖與圖表**：HTML5 Canvas API (用於運動學動畫與動態圖形繪製)[cite: 1]
* **佈署平台**：GitHub Pages[cite: 1, 2]
